# UI Workflow Pointer

Whenever you are asked to create, modify, audit, or brainstorm User Interfaces (UI) or frontend code, you MUST:
1. Actively check and read the `frontend-ui-engineering` skill.
2. If the task involves polishing, animations, or micro-interactions, actively read the `better-ui` and `improve-animations` skills.
3. Keep the `WebInterfaceGuidelines` (located in the rules directory) in mind as your foundational design heuristic.

Do not start writing frontend code without first consulting these specialized UI skills.
